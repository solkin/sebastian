# Sebastian v1.8.1

A security toolchain patch on top of [v1.8.0](v1.8.0.md) (first Docker Hub image
of the v1.8 line).

## Changes

- Build and Docker image updated to **Go 1.26.11** (fixes `GO-2026-6859` in
  `net/http` `MaxBytesReader`).
- Updated `golang.org/x/crypto` to `v0.59.0` (fixes `GO-2026-5932`) and
  `golang.org/x/sys` to `v0.50.0`.

## Upgrade

See [v1.8.0](v1.8.0.md) for the full hardening, lock offloading, and strict
config changelog.

## Validation

Verified with `govulncheck v1.9.0` on Go 1.26.11 (source and release binary: 0
vulnerabilities), `go vet`, and the CI Linux race, Windows build, and Docker
smoke test workflows.

## Images

Images are published for `linux/amd64` and `linux/arm64`:

```sh
docker pull solkin/sebastian:1.8.1
```

Version aliases: `1.8`, `1` and `latest`.
